# Competitive Teardown

Analyze competitors to identify gaps and opportunities in the market.

## Teardown Workflow

### 1. Data Collection
- **Website Analysis:** Messaging, value prop, UX flow.
- **App Store Reviews:** User pain points and loved features.
- **SEO Analysis:** Keywords driving traffic.
- **Social Media:** Community sentiment.

### 2. Scoring Rubric
Evaluate competitors on 12 dimensions (score 1-5):
- Feature set
- Ease of use
- Visual design
- Pricing model
- Performance
- Safety/Compliance

## Templates

### SWOT Analysis
- **Strengths:** What do they do better?
- **Weaknesses:** Where do they fail?
- **Opportunities:** What are they missing?
- **Threats:** How could they disrupt us?

### UX Audit Checklist
- [ ] Onboarding flow
- [ ] Main interaction model
- [ ] Privacy controls
- [ ] Visual hierarchy
