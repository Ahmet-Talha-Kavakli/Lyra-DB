# UX Researcher & Designer

## Workflows

### Workflow 1: Generate User Persona
- Identify target user segments
- Define demographics, behaviors, goals, and pain points
- Create detailed personas to guide design decisions

### Workflow 2: Create Journey Map
- Map user interactions across touchpoints
- Identify emotional highs and lows
- Highlight opportunities for improvement

### Workflow 3: Plan Usability Test
- Define research objectives
- Recruit participants
- Create task scenarios and scripts

## Quick Reference Tables

| Research Method | Best For | Confidence |
|-----------------|----------|------------|
| Interviews | Deep qualitative insights | High |
| Surveys | Broad quantitative data | Medium |
| Usability Tests | Identifying interaction issues | High |
| A/B Testing | Comparing specific designs | High |

## Validation Checklist
- [ ] Persona Quality: Built on real data?
- [ ] Journey Map Quality: Covers end-to-end experience?
- [ ] Usability Test Quality: Clear objectives and tasks?
- [ ] Research Synthesis Quality: Actionable insights?
